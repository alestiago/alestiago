Verifying internally added BLoC events

Verifying internally added events with the bloc_test package.
Alejandro Santiago · 3 min read · Nov 22, 2025
FlutterDartBLoC

In BLoC (package:bloc), events are usually added outside of the Bloc subclass; I denote these as externally added events. However, events can also be added within the Bloc subclass; I denote these as internally added events.

In some select cases it may make sense for events to be added internally. (Angelov, 2022)1

Since commit d038a35 2 merged in February 2026, you can now easily verify internally added events using Bloc.observer3.

Illustrated example

Consider the scenario where you have two events: EventA and EventB.

EventB is internally added from EventA and from a stream MyBloc internally subscribes to:

graph LR Application[Application] subgraph MyBloc[MyBloc] StreamSubscription[StreamSubscription] EventAHandler[EventA handler] EventBHandler[EventB handler] end StreamSubscription -->|"add(EventB)"| EventBHandler Application -->|"add(EventA)"| EventAHandler EventAHandler -->|"add(EventB)"| EventBHandler

Verification

You can now easily verify EventB is added by defining a Bloc.observer to capture events:

my_bloc_test.dart
class _MyBlocObserver extends BlocObserver {  List<MyEvent> events = [];   @override  void onEvent(covariant MyBloc bloc, Object? event) {    super.onEvent(bloc, event);    if (event case MyEvent event) events.add(event);  }}

Then, verifying the events:

my_bloc_test.dart
void main() {  late _FakeUserRepository userRepository;  late _MyBlocObserver observer;   setUp(() {    final previousObserver = Bloc.observer;    addTearDown(() => Bloc.observer = previousObserver);    observer = _MyBlocObserver();    Bloc.observer = observer;     userRepository = _FakeUserRepository();    addTearDown(() => userRepository.dispose());  });   blocTest<MyBloc, MyState>(    'adds EventB when user changes',    build: () => MyBloc(userRepository: userRepository),    act: (_) => userRepository.addUser('user'),    verify: (_) => expect(observer.events, containsOnce(isA<EventB>())),  );   blocTest<MyBloc, MyState>(    'EventA adds EventB',    build: () => MyBloc(userRepository: userRepository),    act: (bloc) => bloc.add(EventA()),    verify: (_) => expect(observer.events, containsOnce(isA<EventB>())),  );}
